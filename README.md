# My Agent Skills

A collection of agent skills and reusable workflows that I commonly use.

## About

This repository contains practical skills for coding agents, including reusable instructions, automation, and shell-based utilities.

## Repository structure

Skills are organized by purpose. Each skill should include its own documentation describing:

- What it does
- When to use it
- Required inputs or dependencies
- Example usage
- Expected output

## Usage

Browse the available skill directories and follow the instructions provided in each skill's documentation.

For shell-based skills, make sure the relevant scripts are executable:

```bash
chmod +x path/to/script.sh
```

Then run the script according to its documented usage.

## Adding a skill

To add a new skill:

1. Create a clearly named directory.
2. Add the skill implementation and supporting files.
3. Include documentation with setup and usage instructions.
4. Keep scripts focused and reusable.
5. Test the skill before committing it.

## Contributing

Improvements, fixes, and new skills are welcome. Please keep contributions focused, documented, and easy to reuse.
